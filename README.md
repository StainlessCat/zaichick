# ZAYCHICK — Автоматизированный учёт сварочных работ и неразрушающего контроля

Комплексная цифровая система оперативного учёта сварочно-монтажных работ, входного контроля труб и деталей (ЛРВ), привязки лайнлиста проекта, неразрушающего контроля (ВИК, РК, УЗК, ПВК, МПК, дубль-контроль) и автоматического формирования исполнительной документации в строгом соответствии с требованиями **СТО Газпром 15-1.1-002-2023**, **ВСН 012-88** и **ГОСТ 16037-80**.

---

## 🏗️ Архитектура и стек технологий

- **Backend & Серверная СУБД:** Node.js 22 LTS, Express, нативный модуль `node:sqlite` (SQLite 3) с журналированием **WAL (Write-Ahead Logging)**, мгновенным транзакционным откликом и fallback-хранилищем `Transactional File DB`.
- **Реальное время (Real-time Broadcast):** Полнодуплексная шина событий **Server-Sent Events (SSE)** для мгновенного информирования клиентов об изменениях без опрашивания сервера (zero-polling).
- **Контроль конкурентного доступа (OCC):** Оптимистическая блокировка версий (`version` для каждого стыка и `globalRevision` для таблиц), возврат аппаратного статуса `HTTP 409 Conflict` и интеллектуальное трехстороннее слияние (3-Way Auto-Merge).
- **Безопасность и RBAC:**
  - **Scrypt KDF:** Защита паролей на базе memory-hard криптографического KDF `scrypt` (NIST / OWASP) с индивидуальной криптографической солью.
  - **Timing-Attack Protection:** Постоянное по времени сравнение хешей через `timingSafeEqual`.
  - **Data Masking:** Маскирование учётных данных на уровне API (пароли и хеши никогда не передаются в браузер).
  - **Field-Level RBAC:** Серверное разграничение прав редактирования на 10 ролей с блокировкой подмены данных на API-эндпоинтах.
- **Согласованное резервное копирование:** Моментальные снимки SQLite через нативный `VACUUM INTO` с предварительным сбросом WAL-журнала (`PRAGMA wal_checkpoint(TRUNCATE)`), ротацией последних 5 копий и API для ручного создания бэкапа (`POST /api/admin/backup`).
- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, автономный офлайн-буфер в `localStorage`.

## 🚀 Быстрый старт на ноутбуке / ПК (Standalone)

Для демонстрации коллегам или работы на автономном ноутбуке:

1. Убедитесь, что установлен **Node.js 22+** (или скачайте с [nodejs.org](https://nodejs.org/)).
2. Запустите файл **`Запустить_ZAYCHICK.bat`** двойным кликом мыши.
3. Скрипт автоматически:
   - Проверит окружение Node.js;
   - При первом запуске установит зависимости и соберёт проект;
   - Запустит единый сервер и откроет систему в браузере по адресу **`http://localhost:3000`**.

Для остановки сервера нажмите `Ctrl + C` в окне командной строки.

## 🐳 Развёртывание на корпоративном сервере (Docker)

Для быстрого промышленного запуска на сервере под управлением Linux / Windows Server:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/StainlessCat/zaichick.git
   cd zaichick
   ```

2. Запустите контейнер через Docker Compose:
   ```bash
   docker compose up -d --build
   ```

3. Проверьте статус контейнера:
   ```bash
   docker compose ps
   ```

База данных и резервные копии сохраняются в постоянный том `./data` на хосте:
- `./data/zaychick.sqlite` — основная база данных;
- `./data/backups/` — архивные копии с ротацией.

## 👥 Ролевая модель доступа (RBAC)

В системе реализовано строгое ролевое разграничение полномочий на 10 производственных ролей:

| Роль | Границы ответственности |
|---|---|
| **Инженер ПТО** | Формирование лайнлиста, заведение стыков, привязка чертежей РД, печать исполнительной документации |
| **Главный сварщик / Технолог ОГС** | Назначение технологических карт (ТК), допуск сварочных материалов, согласование разнотолщинности |
| **Мастер СМР / Прораб** | Внесение дат фактической сборки и сварки, назначение клейм сварщиков, параметров подогрева |
| **Специалист ЛНК / Дефектоскопист** | Внесение результатов ВИК, РК, УЗК, ПВК, МПК, номеров заключений, статусов годности/брака |
| **Начальник лаборатории НК** | Утверждение заключений НК, согласование назначения дубль-контроля |
| **Инженер строительного контроля** | Приёмка стыков, подтверждение устранения замечаний, дубль-контроль |
| **Руководитель проекта** | Мониторинг готовности трубопроводов, эквивалентных дюймов (EDI), аналитика дефектов |
| **Администратор системы** | Управление пользователями, принудительное разрешение конфликтов (forceOverwrite), создание бэкапов |

## ⚙️ Переменные окружения и безопасность развёртывания

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт HTTP-сервера системы |
| `NODE_ENV` | `development` | Режим работы (`production` включает строгую защиту API и раздачу скомпилированного бандла) |
| `ZAYCHICK_REQUIRE_AUTH` | `true` | Обязательная сессионная аутентификация для чтения (`/api/db/state`, SSE) и записи данных |
| `INITIAL_ADMIN_PASSWORD` | *(уникальный в Docker)* | Пароль учётной записи `admin` при создании новой БД. **ВНИМАНИЕ:** в production ОБЯЗАТЕЛЬНО задавайте сложный пароль через `.env` или Docker Secret! |
| `ENABLE_TEST_ROUTES` | `false` | Разрешение тестовых маршрутов имитации конфликтов OCC (в production строго отключены) |

> [!IMPORTANT]
> **Транспортная безопасность (TLS/HTTPS):** Для защиты логинов, паролей и токенов сессий от перехвата в корпоративной сети приложение должно эксплуатироваться за TLS reverse proxy (Nginx, Traefik, Envoy, Caddy) с валидным SSL/TLS-сертификатом либо внутри изолированного защищённого VPN-периметра.

## 🧪 Тестирование и контроль качества

Система покрыта комплексным набором из **33 юнит- и интеграционных тестов**, включая проверку сохранения парольных хешей при синхронизации и сквозное восстановление БД из резервных копий:

```bash
# Запуск тестов логики сварки, OCC, Газпром, RBAC, бэкапов и криптографии
npm test

# Строгая проверка статической типизации TypeScript
npm run lint

# Сборка production-бандла Vite
npm run build
```

## 📄 Соответствие нормативной документации

- **СТО Газпром 15-1.1-002-2023** (49 специализированных граф журнала, учёт разнотолщинности, правила одного ремонта);
- **ВСН 012-88 (Часть II)** (Оформление исполнительной производственной документации);
- **ГОСТ 16037-80** (Типы сварных соединений стальных трубопроводов: С17, У19, С53 и др.);
- **Правила НАКС** (Автоматический расчёт сроков действия и статусов аттестационных удостоверений сварщиков).
